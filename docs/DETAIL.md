# 对话计费

在内置 token 用量胶囊旁边增加一个人民币消费胶囊，显示**本对话累计消费**与**当前轮消费**。
内置胶囊保持原样，缓存命中率等读数不受影响。

## 显示内容

- 底部 dock：`累计 ￥0.21868 · 本轮 ￥0.21868`，点击打开明细。
- 明细：本轮与累计各一组 token 桶（未缓存输入 / 缓存读取 / 缓存写入 / 输出）、缓存命中率，以及按
  `提供方/模型 · 档位 × 次数` 分组的金额；上下文压缩摘要会单列为“压缩摘要”。
- 每轮回复下方可选的「本轮」读数（默认关闭，插件页开启）。

## 计费口径

| 提供方 | 币种 | 分档 |
| --- | --- | --- |
| DeepSeek | 人民币（官网原价，**不做汇率折算**） | 北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰，其余（含周末）为空闲；按需求不区分法定节假日 |
| Grok / xAI | 美元价 × 配置汇率（默认 6.7） | 单次请求 prompt ≥ 200,000 tokens 的整次请求按长档计价 |

- 金额保留 **6 位小数**，第 7 位四舍五入，去尾零；非零但不足 1e-6 的显示为 `￥<0.000001`。
- 缓存写入在两家都没有独立费率，按输入价计。
- 推理 token 属于输出子集，不重复计价。
- 带 provider usage 的上下文压缩调用按同一套模型费率计入总消费和 token。
- 未配置价格的模型不计入合计，并在明细中单列。主胶囊显示 `￥—` 或 `￥已知金额+`，不会把它伪装成 ￥0。

## 更新计费规则

设置 → 插件 → 对话计费页面的「从官网更新计费规则」按钮：

1. 并发抓取 `api-docs.deepseek.com/zh-cn/quick_start/pricing` 与 `docs.x.ai/developers/pricing.md`；
2. 每次请求 8 秒超时，最多 3 次尝试，仅对网络错误、5xx、429 退避重试；
3. 解析后按**基础结构签名**校验（币种、主要计价维度、双时段/双档行）；
4. 结果分三类：`ok` 全部更新、`partial` 部分更新、`mismatch` **不写入**并提示「计费规则不匹配」。

`mismatch` 表示官网计价框架已变化（例如新增按次计费、改为阶梯总价、维度增减），
此时旧价表继续生效，需要更新插件代码后适配。抓取失败同样不会影响现有数字。

计费范围是带 provider usage 的模型 token 调用，包括普通助手请求和上下文压缩摘要。
没有记录 usage 的辅助模型请求，以及图片、语音、OCR、批处理、优先处理和服务端工具调用等
非文本 token 费用，不属于当前统计口径。

## 关闭与恢复

- 插件行停用（Plugins → 本插件）：客户端模块卸载，胶囊与每轮读数移除，页面回到安装前原样。
- 插件页「在对话中显示消费」开关：只隐藏 UI，宿主仍在计算，重新打开数字连续。
